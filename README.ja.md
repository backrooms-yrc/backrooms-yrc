高校生で、個人開発をしています。**Rcst Network Studio** を運営し、Web アプリ、チャットボット、セルフホスト向けのサービスを開発しています。

中国語版ウィキペディアでは、主に地元の学校や教育に関する記事を編集しています。趣味で二次創作小説を書いたり、架空のテレビ局を企画したりしています。 [ウィキペディア利用者ページ](https://zh.wikipedia.org/wiki/User:Rcst20) · [創作作品](https://github.com/backrooms-yrc/Tsumugi-Yuzuha-Fanfics)

## プロジェクト

| プロジェクト | 概要 |
| --- | --- |
| [CurrentMusic](https://github.com/backrooms-yrc/CurrentMusic) | セルフホストできる音楽サービス。Web、Android、Windows に対応。 |
| [CurrentCortex](https://github.com/backrooms-yrc/astrbot_plugin_currentcortex) | 楽曲リクエスト、メディアリンクの解析、グループチャット向け機能を備えた AstrBot プラグイン。 |
| [dsh-openai-gateway](https://github.com/backrooms-yrc/dsh-openai-gateway) | DeepSeek Harness を OpenAI 互換 API から利用するためのゲートウェイ。 |
| [SmartYRC](https://github.com/backrooms-yrc/SmartYRC-) | HTML、CSS、JavaScript で作った AI チャットのフロントエンド。 |
| [The RCST Video Analysis](https://github.com/backrooms-yrc/The-RCST-Video-Analysis) | 動画リンクを解析するサイトのテンプレート。 |

[すべてのリポジトリ](https://github.com/backrooms-yrc?tab=repositories)
